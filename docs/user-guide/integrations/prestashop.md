# PrestaShop 8

Official module (tested on PrestaShop 8.1.7):

[https://github.com/vsys-host/prestashop-8-shkeeper-payment-module](https://github.com/vsys-host/prestashop-8-shkeeper-payment-module)

Configure SHKeeper base URL and API key in the module. Callbacks must return HTTP 202 and should [verify HMAC](../../getting-started/webhook_verification.md).
