# OpenCart 3

Official module (tested on OpenCart 3.0.3.9):

[https://github.com/vsys-host/opencart-3-shkeeper-payment-module](https://github.com/vsys-host/opencart-3-shkeeper-payment-module)

Configure SHKeeper base URL and API key in the module. Callbacks must return HTTP 202 and should [verify HMAC](../../getting-started/webhook_verification.md).
